# 作品文件夹 —— 以后加照片只动这里

把照片丢进对应文件夹就行，**不用改任何代码**。

```
作品/
├── 精选/     ← 这几张会显示在首页
├── 日系/
├── 街拍/
├── 夜景/
└── 日常/
```

## 怎么更新网站

1. 把照片放进 `作品/` 下面某个文件夹
2. **双击 `web\更新网站.bat`**，它会自动检查、打包、上传，最后显示「上传成功」
3. 等 1~2 分钟，GitHub 会自动重新构建并发布到 <https://liitdoog.github.io/>

> 双击前记得先把代理客户端打开（Clash 之类），不然连不上 GitHub —— 脚本会提醒你。
> 不想双击的话，在 `web` 目录里执行 `git add -A && git commit -m "更新作品" && git push`，效果一样。

**想撤下某张照片**：把文件从文件夹里删掉，再跑一次同样的流程就行。

## 几条规则

**文件夹名 = 网站上的标签页。**
新建一个文件夹（比如 `古风/`），网站就会自动多出一个「古风」标签页。删掉文件夹，标签页也跟着消失。
标签页顺序按拼音排，想自己定顺序就在文件夹名前加数字：`1-日系`、`2-街拍`。

**照片名 = 作品标题。**
`窗边.jpg` 在网站上就显示成「窗边」。

**想控制先后顺序，给文件名加数字前缀。**
`01-窗边.jpg`、`02-逆光.jpg` 会排在没有编号的照片前面。
前缀只是排序用的，标题里不会显示出来。

**`精选/` 里的照片会出现在首页。**
它同时也是作品页上的一个标签页，不会「藏起来」。
想让某张照片上首页，就把它（复制一份也可以）放进 `精选/`。

## 照片格式

- **建议用 JPG。** 相机原图直接丢进来就行，构建时会自动压到短边 1080px（和微信一样），你不需要自己缩图。
- **iPhone 的 HEIC 不行。** 需要先在手机「设置 → 相机 → 格式」里选「兼容性最佳」，或者用电脑「导出为 JPEG」。放 HEIC 会导致构建失败并明确提示你（不会悄悄漏掉照片）。
- TIFF 会自动转成 JPG。
- PNG 只有带透明通道时才保留 PNG，否则也转成 JPG。

## 两个注意点

- **照片会进入 Git 历史，删掉也不会让仓库变小。** 建议单张原图别超过 20MB，先在相册里导出成「大」尺寸再放进来。
- **仓库是公开的**，放进去的原图别人能看到、能下载，介意的话先压一下再放。

## 本地预览

```bash
npm run dev
```

注意：新加了照片后要**重新跑一次** `npm run dev` 才能在本地看到（网页刷新不够）。
推送到 GitHub 之后线上是自动生效的，不用管这个。

> 每个文件夹里的 `.gitkeep` 是占位文件，用来让 Git 记住这些空文件夹，别删。
